# Text-to-Image Generator

A deep learning project for generating images from natural language text prompts.

## Project Overview

This project aims to build a text-to-image generation system using modern diffusion models. It is being developed as part of a Summer Internship under the mentorship of a professor at NIT.

## Features

- Generate images from text prompts
- Prompt preprocessing
- Modular project structure
- Google Colab GPU support
- PyTorch and Hugging Face Diffusers
